# Medieval Fantasy City Builder

Early Access medieval fantasy city builder built with Godot 4.7.2 .NET and C#.

## Current development strategy

- Engine: Godot 4.7.2 .NET
- Language: C#
- Repository: Git
- Primary AI coding agent: OpenCode
- Secondary AI coding assistant: Continue
- Local models: Ollama
- Art tools: Blender, Material Maker, Krita, Inkscape, ComfyUI
- Development target: Windows first, with Steam Early Access as the initial release target.

## Important

This repository is in the prototype/design-to-implementation transition.

Do not attempt to build the complete game in one pass.

Implement small vertical slices, run them, test them, document results, and commit working milestones.
